# نقشهٔ مهاجرت TradeNova به نسخهٔ واقعی

این پوشه زیرساخت و قراردادهای اولیه را مستند می‌کند؛ **خودش اتصال واقعی پرداخت، نگهداری رمزارز یا معامله ایجاد نمی‌کند**. تا وقتی ارائه‌دهندهٔ مجاز انتخاب، بک‌اند عمومی مستقر، احراز هویت و آزمون امنیتی انجام نشده، `TRADING_LIVE_ENABLED=false` و `WITHDRAWALS_LIVE_ENABLED=false` بمانند.

## معماری پیشنهادی
- Frontend Mini App: فقط نمایش داده و ارسال درخواست؛ هرگز منبع حقیقت موجودی نیست.
- API backend: اعتبارسنجی Telegram `initData` با HMAC سمت سرور، مجوزدهی هر درخواست و محدودسازی نرخ.
- PostgreSQL: کاربران، درخواست‌ها، دفترکل دوطرفه، رویدادهای webhook و سفارش‌ها.
- Payment adapter: واریز ریالی/پرداخت فقط از ارائه‌دهنده‌ای که فعالیتش برای کشور هدف مجاز است؛ تأیید پرداخت فقط از webhook امضاشده یا API تأیید سمت سرور.
- Crypto adapter: فقط ارائه‌دهندهٔ مجاز با webhook امضاشده، تأیید تعداد تأییدهای شبکه و بررسی آدرس/شبکه.
- Exchange adapter: کلیدهای API فقط در سرور، با حداقل دسترسی و بدون مجوز برداشت؛ ابتدا sandbox/paper trading.
- Withdrawal workflow: درخواست، بررسی ریسک، رزرو وجه در دفترکل، اجرای ارائه‌دهنده، تطبیق وضعیت و رسیدگی به خطا. دکمهٔ «تأیید» در پنل به‌تنهایی نباید پول را جابه‌جا کند.

## ترتیب پیاده‌سازی
1. انتخاب کشورها و مدل قانونی کسب‌وکار؛ بررسی محدودیت ایران و هر سرویس قبل از ثبت‌نام.
2. استقرار API روی HTTPS و PostgreSQL مدیریت‌شده؛ پیکربندی secrets در environment/secret manager.
3. اعتبارسنجی Telegram initData و نقش‌های مدیر در سرور؛ حذف هر مسیر عمومی برای تأیید مدیر.
4. دفترکل غیرقابل‌تغییر، تراکنش‌های اتمیک، کلید idempotency، محدودیت مبلغ و ثبت audit log.
5. پیاده‌سازی و تست adapter یک ارائه‌دهندهٔ پرداخت/کیف پول واقعی.
6. اجرای آزمون‌های دوباره‌ارسال webhook، پرداخت تکراری، برداشت هم‌زمان، قطعی سرویس، بازپرداخت و بازیابی backup.
7. فعال‌سازی محدود با سقف پایین؛ پس از تطبیق حساب‌ها و بازبینی امنیتی، افزایش تدریجی.

## نکتهٔ مهم
`MODE=live` یا تغییر یک گزینه در رابط، سیستم را واقعی نمی‌کند. اگر adapter معتبر و پیکربندی کامل موجود نباشد، درخواست واقعی باید با خطای امن رد شود، نه اینکه موجودی آزمایشی تغییر کند. این بسته همچنان در حالت Demo اجرا می‌شود و نسخهٔ عملیاتی پول واقعی نیست.
