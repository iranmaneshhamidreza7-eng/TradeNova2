# چک‌لیست قبل از پول واقعی

- [ ] کشور هدف، مجوزها، KYC/AML، مالیات و محدودیت‌های تحریم بررسی شده‌اند.
- [ ] ارائه‌دهندهٔ پرداخت/کیف پول/صرافی در کشور هدف قانوناً قابل استفاده است.
- [ ] `Telegram.WebApp.initData` روی سرور اعتبارسنجی می‌شود؛ user ID از درخواست قابل جعل گرفته نمی‌شود.
- [ ] تمام مسیرهای مدیریت دارای احراز هویت و RBAC سمت سرور هستند.
- [ ] موجودی از دفترکل سرور محاسبه می‌شود، نه از localStorage.
- [ ] webhookها امضاسنجی و تکرارشان idempotent هستند.
- [ ] رزرو برداشت و debit/credit در تراکنش دیتابیس اتمیک انجام می‌شود.
- [ ] کلیدها در frontend/repository نیستند؛ برداشت از کلید صرافی غیرفعال است.
- [ ] حداقل/حداکثر مبلغ، کارمزد، محدودیت نرخ، تشخیص تقلب و audit log وجود دارد.
- [ ] sandbox، پرداخت تکراری، webhook جعلی، برداشت هم‌زمان، قطعی سرویس و restore پشتیبان تست شده‌اند.
- [ ] مانیتورینگ، هشدار، پشتیبان‌گیری و روند تطبیق حساب‌ها فعال است.
- [ ] بازبینی امنیتی مستقل انجام شده و ابتدا با سقف پایین راه‌اندازی می‌شود.

**هر مورد تیک‌نخورده = فعال‌نکردن پول واقعی.** این چک‌لیست تضمین قانونی/امنیتی نیست و جای مشاورهٔ حرفه‌ای را نمی‌گیرد.
