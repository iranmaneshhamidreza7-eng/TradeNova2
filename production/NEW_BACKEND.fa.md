# نسخهٔ بعدی: موتور آزمایشی سمت سرور

این نسخه یک **موتور آزمایشی مستقل** با SQLite و API دارای احراز هویت تلگرام اضافه می‌کند. اجرای آن از طریق `bash production/START_SECURE_DEMO.sh` است. موتور حتی اگر صفحهٔ مینی‌اپ بسته شود، **تا وقتی فرایند سرور روشن باشد** ادامه دارد؛ برای اجرای شبانه‌روزی به میزبان دائمی نیاز است.

**مهم:** این API هنوز به صفحهٔ فعلی مینی‌اپ و پنل مدیریت متصل نشده است. صفحهٔ فعلی همچنان از موتور مرورگری و localStorage استفاده می‌کند. این قابلیت یک زیرساخت آزمایشی مرحله‌ای است، نه ادعای اتصال کامل. `/health` بدون ورود و `/api/me` فقط با هدر معتبر `X-Telegram-Init-Data` کار می‌کند. کاربران جدید بدون موجودی، اشتراک و مجوز ربات ایجاد می‌شوند؛ هنوز پنل مدیریت امن برای اعطای این مجوزها وجود ندارد. هیچ راهی برای فعال‌سازی معاملهٔ واقعی در این سرویس نیست.

## امنیت و محدودیت‌ها
- برای استقرار اینترنتی حتماً HTTPS و reverse proxy معتبر لازم است؛ خود سرور پیش‌فرض فقط روی 127.0.0.1 گوش می‌دهد.
- `TRADENOVA_BOT_TOKEN` فقط در متغیر محیطی سرور قرار بگیرد و هرگز در فایل‌های عمومی GitHub یا کد مرورگر ذخیره نشود.
- endpoint ارسال پیام موجود در `telegram-server.py` برای انتشار عمومی امن نیست و باید پیش از انتشار غیرفعال یا بازنویسی شود.
- قیمت‌ها ساختگی‌اند؛ سودها تضمین‌شده یا واقعی نیستند. این پروژه هیچ سفارش واقعی ثبت نمی‌کند.
